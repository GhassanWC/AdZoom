# Framevo Desktop — release notes

The release script reads this file and copies the newest section's bullets into
the website's release manifest, so the notes on /download are the same words
written here. Newest version first; one `## <version>` heading per release.

## 0.1.0

- First public build of the Framevo desktop app.
- Local-first editing: projects, media and the timeline live on your machine.
- Local GPU-accelerated MP4 export using the same render core as cloud exports.
- Sign in with your Framevo account to sync cloud projects; works offline either way.
- Automatic updates, installed on quit so an export is never interrupted.
